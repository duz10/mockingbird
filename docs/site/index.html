Mockingbird

Local-first voice dictation and meeting capture for Windows and macOS. Knowledge graph capture on Windows today. Fully on-device, zero telemetry.

What it does

Voice dictation

Press a global hotkey, speak, and the transcript pastes into whatever app has focus. Speech-to-text runs locally via Whisper. Optional cleanup polishes disfluencies and applies your custom dictionary.

Meeting capture

Records the microphone and system audio on separate channels, transcribes each locally, then merges them with speaker attribution. A post-call summary is available if you opt in to a local or cloud LLM.

Knowledge graph capture

A fast-note mode that extracts entities and tags from every snippet, then projects them into wiki-linked Markdown. Optional Obsidian vault sync turns captured fragments into a navigable knowledge base.

Windows only for now. The knowledge graph, activity capture, and mobile sync layers have not yet been ported to macOS.

Local-first by default

Mockingbird runs entirely on your machine. No telemetry. No analytics. No phone-home. API keys for optional cloud surfaces (Claude, Unsplash) are encrypted via the OS keystore - Windows DPAPI on Windows, the Keychain on macOS - and never leave your computer except in the direct API call you opted into.

Quick start

Windows

  1. Download the MSI from the Releases page.
  2. Run the installer. Windows SmartScreen will show a warning because the beta is not yet code-signed. That is normal for indie Windows software. Click More info, then Run anyway.
  3. Press the dictation hotkey and start speaking. The transcript pastes into the app that had focus.

macOS (Apple Silicon)

Requires macOS 15 (Sequoia) or newer on Apple Silicon. Install with Homebrew (easiest) or download the .dmg. The speech models are bundled in the app, so there is nothing extra to download for basic dictation.

  1. Install it with Homebrew. The first line adds the tap; the second installs the app:
    brew tap duz10/mockingbird https://github.com/duz10/mockingbird
    brew install --cask mockingbird
    Prefer not to use Homebrew? Download Mockingbird_x.y.z_aarch64.dmg from the Releases page, open it, and drag Mockingbird into Applications.
  2. First launch: a one-time "Open Anyway" step. Because this is a free, unsigned app (no paid Apple certificate), macOS blocks the first open - this is expected, not a virus warning. Open System Settings -> Privacy & Security, scroll to the bottom, click Open Anyway next to Mockingbird, and confirm. (Comfortable in Terminal? xattr -dr com.apple.quarantine /Applications/Mockingbird.app does the same thing.)
  3. Allow three permissions when the app asks (or under System Settings -> Privacy & Security): Microphone, Input Monitoring (for the Right Option push-to-talk key), and Accessibility (so it can paste into your app). Grants take effect after you quit and reopen Mockingbird. Screen Recording is only needed if you also want meeting capture to record the other participants.
  4. Press Right Option and start talking. Release to paste into the app that had focus. Update later with brew upgrade --cask mockingbird.

Optional cleanup (both platforms): dictation works on its own. For the optional AI pass that removes "um"/"uh" and fixes punctuation, install Ollama (free) and pull one model - ollama pull qwen2.5:7b-instruct-q4_K_M on machines with 16 GB+ RAM, or ollama pull qwen2.5:3b-instruct-q4_K_M on an 8 GB Mac (the app picks the smaller one automatically). Skip it and you still get accurate raw transcripts.

FAQ

Why is there a SmartScreen warning?

The beta is not code-signed. Windows treats unsigned installers as unknown publishers and prompts you to confirm. This is the same friction every indie Windows app hits before paying for a code-signing certificate. See SECURITY.md for details on what we do and do not sign.

Does it work on macOS?

Yes - on Apple Silicon Macs running macOS 15 (Sequoia) or newer. Install it with Homebrew or a downloadable .dmg (see the macOS quick start). Because the app is free and unsigned, the first launch needs a one-time System Settings -> Privacy & Security -> Open Anyway approval - normal for indie apps, not a sign anything is wrong. Dictation and meeting capture both work with the same local-first, on-device model as Windows, and the speech models are bundled in the app. The knowledge graph, activity capture, and mobile sync layers are Windows-only for now and have not yet been ported.

Where does my data live?

Locally - %LOCALAPPDATA%\Mockingbird on Windows, ~/Library/Application Support/com.dustin.mockingbird on macOS. Transcripts, settings, the SQLite database, and any vault projection all stay on your machine. Full detail in PRIVACY.md.

Can I use my own LLM for cleanup and summarization?

Yes. Mockingbird talks to a local Ollama server out of the box and works with any chat model Ollama supports. Cloud providers (Claude) are optional and opt-in.

Is this open source?

Yes, MIT licensed. Source at github.com/duz10/mockingbird.

I want to contribute.

Please do. Start with CONTRIBUTING.md, then open an issue or a discussion describing what you have in mind before writing a lot of code, so we do not duplicate work. I am solo and review on evenings and weekends, so expect a slow response rather than no response. If you need something faster than I can ship it, fork it. That is a supported outcome, not a failure.
